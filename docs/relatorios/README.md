# 📁 Relatórios e Entregáveis — KIIRA Predict

Documentação oficial do projeto **emb2-analise-motor-ac** para o programa EmbarcaTech 2025.

## Arquivos desta pasta

| Arquivo | Descrição |
|---|---|
| `Relatorio_Arquitetura_TESTE_Branch.pdf` | Relatório de arquitetura da branch de testes |
| `Relatorio_Empresarial_Viabilidade.pdf` | Análise de viabilidade empresarial e modelo de negócio |
| `Relatorio_Processo_Implementacao.pdf` | Processo e etapas de implementação do sistema |
| `Relatorio_Requisitos.pdf` | Levantamento e especificação de requisitos |
| `Relatorio_Tecnico_Arquitetura.pdf` | Relatório técnico da arquitetura do sistema |
| `Diagramas_Sistema.pdf` | Diagramas de blocos, fluxo e arquitetura do sistema |

## Como adicionar os arquivos

1. Copie os PDFs da sua pasta de Downloads
2. Cole nesta pasta: `docs/relatorios/`
3. Confirme que os nomes batem com a tabela acima (remova o ` (2)` do nome se houver)
